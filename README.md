# matkakohteet

Käynnistysohjeet:

Luo tietokanta komennolla: sqlite3 database.db < schema.sql

Käynnistä sovellus komennolla: flask --app src/app.py run

Sovelluksen toiminnallisuus:

- Käyttäjä pystyy luomaan tunnuksen ja kirjautumaan sisään sovellukseen.
- Käyttäjä pystyy lisäämään, muokkaamaan ja poistamaan matkakohteita.
- Käyttäjä pystyy lisäämään kuvia matkakohteesta.
- Käyttäjä näkee sovellukseen lisätyt matkakohteet.
- Käyttäjä pystyy etsimään matkakohteita hakusanalla.
- Sovelluksessa on käyttäjäsivut, jotka näyttävät tilastoja ja käyttäjän lisäämät matkakohteet.
- Käyttäjä pystyy valitsemaan matkakohteelle yhden tai useamman luokittelun (esim. hintaluokka, sijainti, turvallisuus).
- Käyttäjä pystyy kommentoimaan matkakohteita.
